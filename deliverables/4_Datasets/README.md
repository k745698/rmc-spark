# Datasets

| Folder | Contents | Source |
|---|---|---|
| `public_datasets/` | `ai4i2020.csv` (+ original `ai4i.zip`): AI4I 2020 Predictive Maintenance, 10 000 records | UCI ML Repository, https://doi.org/10.24432/C5HS5C |
| | `creditcard.csv`: Credit Card Fraud Detection, 284 807 anonymised (PCA) transactions | ULB Machine Learning Group via Kaggle, https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud |
| `experiment_raw_data/` | Raw measurements of every experiment: `minimum/` (36-run matrix), `cases/` (2 ML case studies), `calibration/`, `smoke/`. Each has `runs.csv` (one line per run), `decisions.jsonl` (controller decisions), `cluster_timeseries.csv`, `events/` (per-stage timings) and `logs/` (Spark driver logs) | Generated in this study |
| `experiment_report_tables_figures/` | Tables 11–12 (CSV/Markdown) and the result figures computed from the raw data | Generated by `analysis/report.py` |

The synthetic taxi-trip and graph datasets are not stored: they are regenerated identically
(seeded) by `jobs/datagen.py`. The public datasets can be re-downloaded with
`scripts/download_data.py --case-studies`; the NYC TLC trip data (optional) with `--tlc-months`.

Note: `creditcard.csv` (144 MB) is over GitHub's 100 MB file limit, so it is not stored in the GitHub
repository; download it from the Kaggle link above (or run `scripts/download_data.py --case-studies`).
