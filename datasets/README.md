# Datasets

| Dataset | Used by | Source | Licence / terms | How to get it |
|---|---|---|---|---|
| Synthetic taxi trips (4 M rows) | `etl_taxi`, `ml_taxi` | generated by `jobs/datagen.py` (seeded, reproducible) | — | `spark-submit ... jobs/datagen.py` |
| Synthetic skewed graph (2 M edges) | `iterative_rank` | generated by `jobs/datagen.py` | — | same |
| Rate source stream | `streaming` | Spark built-in `rate` source | — | nothing to download |
| NYC TLC Yellow Taxi trip records (optional, `--source tlc`) | `etl_taxi` | NYC Taxi & Limousine Commission, <https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page> | public, NYC open data terms | `python scripts/download_data.py --tlc-months 2024-01` |
| AI4I 2020 Predictive Maintenance | `case_maintenance` (Section 18) | UCI Machine Learning Repository, id 601 | CC BY 4.0 | `python scripts/download_data.py --case-studies` |
| Credit Card Fraud Detection (ULB) | `case_fraud` (Section 18) | Machine Learning Group, ULB (mirror used by the TensorFlow tutorials) | Open Database License (DbCL) | same |

Downloaded files land in `datasets/tlc/` and `datasets/case/`. They are git-ignored because of their size.
Load them into MinIO with `jobs/ingest_local.py` (see the main README).

## Data availability statement (for the manuscript)

> The synthetic datasets analysed in this study are generated deterministically by the scripts in the
> project repository [GitHub link]. The public datasets are available from the NYC Taxi & Limousine
> Commission (TLC Trip Record Data), the UCI Machine Learning Repository (AI4I 2020 Predictive
> Maintenance Dataset, id 601) and the ULB Machine Learning Group (Credit Card Fraud Detection). The raw
> experiment logs and measurements generated during the current study are available in the same
> repository under `results/`.
